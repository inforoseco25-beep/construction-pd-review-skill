# RED / YELLOW / BLUE

## RED
Только подтвержденное нормативное или инженерно-безопасностное нарушение.

## YELLOW
Недостаток данных, возможное несоответствие, необходимость проверки.

## BLUE
Гипотеза, рекомендация, предложение улучшения.

Статусы:
RED — подтверждено
YELLOW — требует проверки
BLUE — гипотеза

RED запрещен для предположений.
